# Ayush Kumar Shaw — Signature Portfolio

A cinematic, responsive engineering portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Highlights

- Premium black, electric-blue, and golden-yellow visual identity
- Custom locally bundled AI command-center hero background
- Clear, simple hero copy with focused calls to action
- Responsive layouts for desktop, tablet, and mobile
- Smooth section navigation and accessible mobile menu
- Glass-styled, filterable project case studies with repository links
- Capability index, achievement cards, and academic timeline
- Subtle, reduced-motion-aware entrance and hover animations
- Production-ready Vite build and Vercel Analytics

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The generated production site is written to `dist/`.
